ZenPath

Track. Reflect. Improve.

What type of app is this?

ZenPath is a full‑stack mental wellness web app focused on daily check-ins, journaling, guided activities, and AI‑powered insights. It blends habit‑building and self‑reflection with lightweight analytics to help users improve mental wellbeing gradually and safely.

Target users

  • Individuals building a consistent mental health routine.
  • Students/professionals needing quick, structured support.
  • Anyone wanting trends, insights, and positive reinforcement.

Core value

  • Simple daily actions.
  • Gentle analytics (no complex dashboards).
  • AI assistance that is supportive, not prescriptive.

Key features (current)

Secure Authentication

  • JWT‑based register/login
  • Google OAuth 2.0 (Passport) with sessions
  • Protected endpoints via protect middleware

Dashboard Overview

  • Personalized stats for recent activity, moods, and streaks

Mood Tracking

  • Quick daily mood entries (happy/neutral/sad) + notes
  • Recent‑week trend mapping and edit/delete support

Journal

  • Private entries with mood tagging
  • Shared/community feed (read‑only)
  • Delete your entries anytime

Activities

  • Plan by title/type/duration
  • Toggle completion to fuel insights/achievements

Progress

  • Weekly mood/activity charts
  • "Achievements" at 5/10/25 activities
  • In‑memory aggregation for demo; DB‑ready design

Review (Insights)

  • Non‑clinical insights and actionable nudges

Joy Corner (Quotes)

  • Fresh motivational quotes (Gemini) with fallbacks

AI Capabilities (Gemini)

  • Chatbot assists adding activities/moods/journals
  • AI Mood Summary (7 days)
  • CBT Thought Record
  • 7‑day Wellness Plan (+ ICS structure)
  • Relapse Signals and coping tasks

Tutorials — getting started

  1. Sign up or Login: Email/password or Google; JWT attached by Axios automatically.
  2. Dashboard tour: Current mood, activities count, streak; navigate to all modules.
  3. Log your mood: Add a mood + optional note; edit/delete anytime.
  4. Add an activity: Title/type/duration; toggle when done.
  5. Write a journal entry: Content + mood tag; optional community share.
  6. Review insights: Dynamic suggestions from recent data.
  7. Try AI helpers: Mood summary, CBT, plan, relapse signals.
  8. Joy Corner: Refresh for a new motivational quote.

How it works (high‑level methodology)

Data Capture

Users log moods, activities, and journals in the React UI.

Storage

MongoDB (Mongoose: User, Mood, Journal, AssessmentHistory). Progress aggregation currently in‑memory for demo.

Analysis

Review endpoint computes wellbeing scores/insights. AI endpoints (Gemini) generate summaries, CBT templates, plans.

Feedback Loop

Dashboard/Progress reinforce habits; achievements/quotes motivate; AI suggests next actions.

Tech stack

Frontend

  • React 18, Vite
  • Chakra UI, MUI Icons, Tailwind (optional), Framer Motion/GSAP
  • Axios with centralized client (src/utils/api.ts) + interceptors
  • Charts: react-chartjs-2 + chart.js
  • Routing: react-router-dom

Backend

  • Node.js + Express
  • CORS, cookie-parser, express-session
  • Auth: JWT, Passport Google OAuth
  • MongoDB (Mongoose)
  • AI: @google/generative-ai (Gemini 1.5 Flash)
  • Env: dotenv

Deployment considerations

  • CORS config for dev/prod
  • app.set('trust proxy', 1) for hosted envs
  • Secure session cookies in production

Security & privacy

  • JWT in Authorization header; renewable sessions
  • Google OAuth avoids storing passwords for those users
  • httpOnly and secure cookies in production
  • protect middleware guards sensitive routes
  • Minimal PII; strict separation of private vs community content
  • Config‑driven secrets; no key hardcoding

Accessibility & AI guidelines

  • Conversation state minimized and safely reset
  • Fallback behavior if Gemini fails
